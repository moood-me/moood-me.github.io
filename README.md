# moood lab

`lab.moood.me` — the organization's GitHub Pages site: one page, the sections of moood's sandboxes. Each section is a
public repository of its own with GitHub Pages on its `main`; under this site's domain GitHub serves it at
`lab.moood.me/<repository>/`.

A new section: Pages turned on in its repository (Settings → Pages → `main`, `/`; a `.nojekyll` at its root), then one
`<a class="section">` added to `index.html` here.
